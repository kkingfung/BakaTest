# Available Skills

## Quick Reference

| Skill | Purpose | Complexity |
|-------|---------|-----------|
| `mvvm-implementation` | Complete MVVM feature workflow | High |
| `battle-system` | Battle system components guide | High |
| `ui-toolkit-design` | UI Toolkit screen design workflow | Medium |

## When to Use Skills vs Commands

### Use Commands When:
- You need a single component (ViewModel, View, Service)
- You want quick boilerplate generation
- You're working on a specific file

### Use Skills When:
- Implementing a complete feature (multiple files)
- Need step-by-step guidance
- Working on complex systems with multiple components

## Usage Examples

### Implement a complete screen
```
Claude, use the mvvm-implementation skill to create a Champion Selection screen
```

This will guide you through:
1. Requirements gathering
2. ViewModel creation
3. View creation
4. UXML design
5. USS styling
6. Integration
7. Review

### Implement battle components
```
Claude, use the battle-system skill to implement the damage calculation system
```

This provides structured guidance for battle system architecture.

### Design a new UI
```
Claude, use the ui-toolkit-design skill to create the Test Result screen
```

This ensures your UI follows project style guidelines.

## Workflow Recommendation

```
Feature Implementation Flow:
1. Use skill for overall guidance
2. Use commands for individual components
3. Use /review-mvvm for quality check
4. Iterate based on feedback
```

## Tips

- Skills are interactive workflows, not one-shot commands
- Claude will ask questions at each step
- You can pause and resume skill workflows
- Skills reference project documentation automatically
